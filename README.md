# Cyber Knight

Three.js で作ったサイバーナイトの可動モデルです。形はすべてコードで生成していて、外部の 3D モデルファイルは使っていません。

## 動かし方

ES モジュールを使うので、ローカルサーバー経由で開いてください。Three.js は CDN から読み込みます。

```sh
npx http-server . -p 8080
# → http://localhost:8080
```

## 機能

- **関節リグ**: 腰・背骨・胸・頭・バイザー・肩・肘・手首・股関節・膝・足首・盾マウントの階層。各関節に可動域(度)があり、角度はその範囲に収まるよう制限されます
- **関節エディタ**: 関節ごとの X/Y/Z スライダー。関節マーカーをオンにすると、画面上で関節をクリックして選べます
- **脚 IK**: 2 ボーンの解析 IK で足を接地させます。腰を下げると膝が曲がり、足は地面に残ります。足を動かすポーズでは自動でステップ(足の持ち上げ)が入ります
- **連動パーツ**: 肩当ては腕に、草摺と前垂れ・後ろ垂れは太ももに、一部だけ追従します
- **バイザー**: ヒンジで開閉します(「素顔」ポーズ)
- **物理**: マントは Verlet 法の布シミュレーション(体との衝突あり)、羽飾りは形を保とうとするバネ付きの鎖
- **ポーズとアクション**: 待機 / 構え / 防御 / 素顔、回転斬り(剣の軌跡つき)/ 突進
- **カラーバリエーション**: 通常 / レッド / ブラック / ゴールド

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `src/knight.js` | 関節定義と装甲メッシュの生成 |
| `src/rig.js` | 関節角度、ポーズ補間、脚 IK、連動パーツ |
| `src/poses.js` | ポーズとアクションのデータ |
| `src/cape.js` | マントの布シミュレーション |
| `src/plume.js` | 羽飾りのシミュレーション |
| `src/trail.js` | 剣の軌跡 |
| `src/materials.js` | マテリアルとカラーバリエーション |
| `src/main.js` | シーン、ライティング、ポストエフェクト、UI |
